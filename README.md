# Glideball downloads and updates

This repository holds Glideball's releases: the Mac app, and the Linux and Windows previews.
Glideball's source isn't here.

- Download Glideball: https://glideball.app/download/
- What's new: https://glideball.app/changelog/
- Feedback, bugs and questions: https://glideball.app/feedback/

Glideball checks this repository once a day for updates and only installs one signed by its developer.
